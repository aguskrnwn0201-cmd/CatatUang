# Required Skills & Knowledge Base - CatatUang

## 1. Frontend Development
* **HTML5 & Semantic Markup:** Penggunaan elemen semantik untuk aksesibilitas dan struktur PWA.
* **Tailwind CSS:** Penguasaan class bawaan Tailwind untuk layout responsive (`flex`, `grid`), pewarnaan, dan komponen mobile.
* **JavaScript (ES6+):**
  * DOM Manipulation & Event Handling.
  * Array Methods (`map`, `filter`, `reduce`) untuk kalkulasi saldo & statistik.
  * LocalStorage API & Web Storage Management.

## 2. Progressive Web App (PWA)
* **Service Worker Lifecycle:** Pemahaman event `install`, `activate`, dan `fetch` untuk strategi caching *Cache-First*.
* **Web App Manifest:** Konfigurasi `display: standalone`, ikon, dan skema warna aplikasi.

## 3. Mobile Hybrid Packaging
* **Capacitor / TWA:** Kemampuan melakukan setup lingkungan Android SDK, mengonfigurasi `capacitor.config.json`, dan build APK via Android Studio.

## 4. UI/UX & Data Formatting
* **Data Formatting:** Pemformatan angka ke mata uang Rupiah (`Intl.NumberFormat('id-ID')`).
* **Chart Integration:** Integrasi library grafik berbasis canvas seperti Chart.js.
